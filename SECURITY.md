# Política de segurança

## Versões com suporte

A versão mantida deste projeto é a que está na branch `main`. Correções de segurança serão feitas nessa versão.

## Como reportar uma vulnerabilidade

Use a opção **Report a vulnerability** na área **Security and quality** deste repositório para enviar um relato privado.

Não publique detalhes da falha em uma issue ou pull request público. No relato, descreva o problema, como reproduzi-lo e qual pode ser o impacto. Não inclua senhas, tokens ou outros dados pessoais.

Usaremos o próprio GitHub para conversar sobre o relato e acompanhar a correção.
